Network Discovery (mDNS)

When on, the bridge advertises itself on your network so you can reach it at esp-bacnet-bridge.local instead of by IP address. Off by default: the responder holds a few KB of memory permanently, and this board has none to spare. Leave it off unless you actually need .local.
